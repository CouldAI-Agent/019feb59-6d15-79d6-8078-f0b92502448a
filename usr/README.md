# BlueStore

A premium Telegram Mini App UI demo for a digital marketplace.

## Overview
BlueStore is a clean, professional, mobile-first frontend template optimized for Telegram Mini Apps (390–430px mobile width). It features a dark navy/black background, premium electric-blue gradients with glow effects, modern glassmorphism cards, and smooth rounded corners.

## Features
- **Home Screen:** User balance, quick actions (Top Up/Withdraw), overview statistics, and popular products.
- **Products Screen:** Marketplace view with category filters and product grid.
- **Balance Screen:** Interactive top-up flow with predefined amounts and demo payment methods (bKash/Nagad).
- **Orders Screen:** Order history with visual status badges (Completed, Processing, Pending).
- **Profile Screen:** User details, statistics, and quick navigation menu.

## Tech Stack
- HTML5
- CSS3 (Custom Variables, Flexbox, CSS Grid, Glassmorphism)
- Vanilla JavaScript (for smooth view transitions)

## Setup & Run
Simply open `index.html` in any modern web browser. The app is completely self-contained in a single file and requires no build steps or backend servers.
